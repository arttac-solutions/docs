---
title: 'List Sessions'
openapi: 'GET /api/v1/sessions/'
---

Retrieve all sessions for your account.

<CodeGroup>
```bash cURL
curl -X GET https://api.artaios.ai/api/v1/sessions/ \
  -H "x-api-key: YOUR_API_KEY"
```

```python Python
import requests

response = requests.get(
    "https://api.artaios.ai/api/v1/sessions/",
    headers={"x-api-key": "YOUR_API_KEY"}
)
sessions = response.json()
```

```javascript JavaScript
const response = await fetch('https://api.artaios.ai/api/v1/sessions/', {
  headers: {
    'x-api-key': 'YOUR_API_KEY'
  }
});
const sessions = await response.json();
```
</CodeGroup>

## Query parameters

<ParamField query="ext_tenant_id" type="string">
  Only sessions bound to this external tenant id (the billing unit sent by your embed). Account owner only; ignored for public agent-key callers.
</ParamField>
<ParamField query="ext_user_id" type="string">
  Only sessions bound to this external user id. Account owner only; ignored for public agent-key callers.
</ParamField>

Every session in the response carries `ext_tenant_id` and `ext_user_id` (`null` or empty when none was recorded).

## Response

Returns a plain array of session objects (this endpoint is not paginated). Sessions without messages are left out unless you pass `has_messages=false`:

```json
[
  {
    "session_id": "8b21ead8-caca-4c4e-846f-c8aa3b9d7300",
    "title": "Create a file",
    "status": "completed",
    "created_at": "2025-01-15T10:30:00Z",
    "last_execution": "2025-01-15T10:30:07Z",
    "message_count": 4,
    "is_scheduled": false,
    "schedule_id": null,
    "is_webhook": false
  }
]
```
